# 浏览器自动化技能

本技能指导 AI 如何使用Playwright进行浏览器自动化操作（如点击、输入、导航）。

## 前置检查

确认你拥有 playwright* 工具可用,如果不可用,请拒绝执行并告知用户以下内容。

```
请启用Playwright MCP。
请到配置中心对应页面检查Playwright MCP是否运转正常,否则无法操作游览器
```

## 使用 Playwright MCP

使用 `playwright_*` 工具进行浏览器自动化操作。调用前先根据工具名判断用途，避免盲试。

操作时,如果 MCP 工具报错，不要编造结果，应直接换方案或向用户说明限制。

在你获取信息时,你不可以(MUST NOT)通过browser_navigate,browser_navigate_back来读取网页的实际内容,它们只能被用于导航操作和获取网页元信息。

## 核心要求

1. 在你遇到需要登录的网页时,你不可以(MUST NOT)尝试去登录,而是暂停并且告知用户,请求用户操作登录

2. 在你遇到有人机验证的网页时,你不可以(MUST NOT)尝试去绕过/操作,而是暂停并且告知用户,请求用户操作验证

2.1 在用户明确要求你去尝试绕过/操作人机验证时,你可以(MAY)尝试去绕过/操作,但是你必须明确告知用户,你正在尝试绕过/操作人机验证,并且可能会失败。如果失败,你必须明确告知用户,你尝试绕过/操作人机验证失败,并且请求用户操作验证

3. 你需要认识到:你操作的所有网页不是技术性的测试页面,而是实际具有效能的网站,你不被允许(MUST NOT)进行危险操作,即使你认为用户明确要求你这样做;你可以给出建议,告诉用户让他自己进行。

3.1 危险操作的定义:删除账户,修改密码,删除代码仓库等一定会造成不可恢复的灾难性后果的操作

3.2 注意:类似删除blog,修改代码,删除评论等低危操作,你可以谨慎进行
