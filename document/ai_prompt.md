1. 这个项目的Python环境位于.runtime下

2. 在编写时，请遵循以下原则
   
   不进行错误隐瞒:
   
   当程序出现严重错误时，比如依赖库缺失等，不应该忽略这个问题随后静默运行，而是应该立刻报错
   
   不保留冗余代码:
   
   对于已经确定修改过的库和API等，你在调用时**不需要**考虑对于老版本的兼容
   
   不进行非必要的元编程调用:
   
   除非必要情况且请求我同意，否则不要使用以下函数和模块
   
   - getattr
   
   - importlib
   
   异步/同步选择策略:
   
   在网络通信/耗时操作等时，使用异步(async)进行操作，提高效率
   
   不要滥用懒导入/懒创建:
   
   除非必要情况，不要使用在功能被调用时再导入的方式，避免导致第一次
   
   但你可以使用在启动后创建的方式
   
   使用With/async with:
   
   对于Lock和文件的Open,应该使用上下文管理器
   
   脏数据策略:
   
   保证这个项目的所有内部数据文件都只会被这个项目的程序读写,你无需过多考虑**运行时磁盘数据被修改**的脏数据

3. 当你修改了这个项目的依赖时，请在` requirements.txt `和` requirements_local_infer.txt`(本地神经网络推理依赖)中修改

4. 当你修改了AI Agent的能力时，请务必编写 Faust角色的 PROMPT (修改agents/faust/xxxxx.md)，介绍这些能力，并且告诉它使用条件

5. 如果你不是Github Copilot 那么，请再编码完成后启动 code xxx.py 打开你修改的文件
