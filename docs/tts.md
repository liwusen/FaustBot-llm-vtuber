# GPT-SoVITS(gpt-sovits 本地 TTS)配置指南

GPT-SoVITS 是基于 VITS 的语音克隆框架，本项目通过它的 HTTP API 做本地语音合成。

项目链接：[RVC-Boss/GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)

当前集成目标版本为 **GPT-SoVITS V5**（2026-10-05 发布）。V5 提供两个底模：

| 底模 | 推理步数 | 特点 | 适用场景 |
|---|---|---|---|
| `v5turbo` | 4 | 快，默认 | 实时对话、直播 |
| `v5dev` | 32 | 质量更高，较慢 | 预生成、对音质要求更高 |

使用本地 TTS 需要显存 >= 4G 的 NVIDIA 显卡。V5 全量包下载约 10.6～10.9 GB，解压后建议预留约 30 GB 磁盘空间；旧版增量升级包约 1.5 GB。

## 1. 选择正确的显卡版本

打开配置程序的「组件」页面。

在 TTS 板块的版本下拉框中选择：

- NVIDIA 50 系列显卡：选择 `NVIDIA 50 系列 (V5)`
- 其他 NVIDIA 显卡：选择 `Standard (V5)`

## 2. 安装或升级 V5

### 新安装

点击 TTS 模块的「下载/重装 V5」，等待进度条走完。

下载过程会完成：下载 7z 全量包 → 解压 → 修正嵌套目录 → 校验 `api.py`、V5 代码与 V5 权重。

### 已有旧版（V2Pro / Bundle）

组件页的「版本」会显示「旧版（V2Pro 及更早）」，此时会出现「升级到 V5（约 1.5GB）」按钮。

点击后确认：

1. 后端会先停止 TTS 服务并等待 5000 端口释放；
2. 下载 V5 增量包（代码 + 两个 V5 SoVITS 底模 + vocoder）；
3. 覆盖到现有安装目录，并把被覆盖的旧文件备份到安装目录下的 `.v5-upgrade-backup/`；
4. 校验失败或取消时自动回滚。

> 增量升级复用现有 runtime。若旧 runtime 与 V5 代码不兼容，日志会给出明确错误，此时请改用「下载/重装 V5」全量包。

## 3. 选择 V5 底模

进入「语音」页面，在「V5 底模」中选择：

- `v5turbo`：默认，适合实时语音；
- `v5dev`：质量更高但更慢。

保存配置后，如果 TTS 服务正在运行，后端会自动重启它使新底模生效；服务未运行时会在下次启动时生效。

## 4. 启动 V5 服务

回到「组件」页面，点击 TTS 模块的「启动服务」。

首次启动需要加载 V5 权重，可能比旧版慢几十秒。多刷新几次，等待服务状态变为绿色「运行中」。

服务启动时会显式传入：

- `-s GPT_SoVITS/pretrained_models/gsv-v5-pretrained/s2Gv5turbo.pth`（或 `v5dev`）
- `-g GPT_SoVITS/pretrained_models/s1v3.ckpt`

因此日志中的模型版本应为 `v5turbo` 或 `v5dev`，不会再回落到 v1 底模。

## 5. 切换 TTS 模式到 gpt-sovits

进入「语音」页面，把 TTS 模式改为 `gpt-sovits`，点击「保存」和「应用」。

参考音频仍通过「TTS 参考音频路径 / 参考文本 / 参考语言」配置，合成前会调用本地服务的 `/change_refer` 注入。

## 6. 日志与排错

TTS 日志统一写到后端根目录的 `log_tts.log`，可在组件页点击 TTS 的「日志」查看。

常见问题：

- **日志提示未找到 GPT-SoVITS 安装**：先在组件页下载 V5 全量包或执行增量升级。
- **日志提示 V5 SoVITS / GPT 权重缺失**：安装不完整，重新执行增量升级或下载全量包。
- **5000 端口被占用**：先停止占用端口的进程；升级时后端也会等待端口释放，超时会中止而不覆盖文件。
- **增量升级失败**：检查 `.v5-upgrade-backup/` 是否已回滚；若旧 runtime 不兼容，改用全量包。
- **服务启动很慢**：V5 首次加载权重需要时间，观察日志中的 `模型版本` 与 `Uvicorn running` 行。
