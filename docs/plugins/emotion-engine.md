# 情绪引擎

给 Faust 一套会随时间和对话变化的**情绪状态**，让它的语气和表现更有「人味」，并在主窗口形象上显示一个表情徽标。

## 它能做什么

- Faust 拥有六种情绪：**愉悦、烦躁、傲慢、好奇、毒舌、无聊**，每种都有强弱。
- 对话会影响情绪：被逗乐会更愉悦，被反复追问可能更烦躁等等。
- 情绪会随时间自然**衰减**回落；长时间没人搭理，它会渐渐「无聊」。
- 主窗口形象旁会显示一个**表情徽标**，用 emoji 表示当前主导情绪（😊😤😏🧐😼😶）。
- 当前心情会影响 Faust 的说话风格。

开启后自动运行，你正常聊天即可感受到变化。

## 启用与面板

在插件页开启后，会出现「情绪系统」管理面板，你可以：

- 查看当前各项情绪的高低；
- 拖动情绪条**手动调整**某种情绪；
- 查看最近 24 小时的情绪变化趋势图（需要联网加载图表）。

## 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 毒舌改写 | 关 | 是否让高「毒舌」时说话更犀利 |
| 情绪衰减速率 | 0.1 | 情绪回落的快慢，越大回落越快 |
| 表情浮层强度 | 50 | 主窗口表情徽标的显示强度 |

## 小提示

- 表情徽标锚定在形象附近，会随主导情绪切换。
- 想让 Faust 情绪更稳定，可调低衰减速率；想让它更「善变」可调高。
- 趋势图需要联网才能显示。
