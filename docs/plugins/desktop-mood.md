# 情绪化桌面 Desktop Mood

让 Faust 感知你的真实桌面环境，并**主动做出反应**——就像一只会观察你的桌宠。它会留意你是否离开、电脑是否吃力、现在几点、你在用什么软件、在听什么歌、外面天气如何等等。

> **仅限 Windows。** 空闲检测、活动窗口、媒体感知等功能依赖 Windows 系统能力，在其他平台上不可用。

## 它能做什么

根据环境，Faust 可能会：

- 你长时间没动 → 打个哈欠动作，或轻声搭话；
- 你回到电脑前 → 主动问候；
- CPU / 内存占用过高 → 提醒你；
- 电量过低 → 弹一张便签提示充电；
- 深夜还在用 → 关心你早点休息；
- 你在用某个软件（如 VS Code）→ 说点应景的话；
- 你在放音乐 → 有所回应。

主窗口右上角还会显示一个小浮层，展示天气和你的活动状态（活动中 / 短暂离开 / 已离开）。

## 启用与管理

在插件页开启后，会出现管理面板，你可以：

- 查看当前采集到的环境信息（心情、空闲、窗口、天气）；
- 手动切换心情（自动 / 雨天 / 温暖 / 暗色）；
- 查看和开关各条**反应规则**（比如只想要「久坐提醒」而关掉其他）。

侧边栏还有开关可显示/隐藏右上角的天气浮层。

## 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 全局冷却 | 180 秒 | 两次主动反应之间的最短间隔，避免频繁打扰 |
| 天气城市 | 自动 | 用于获取天气的城市 |
| 窗口监控 | 开 | 是否留意当前使用的软件 |
| 空闲检测 | 开 | 是否检测你离开/回来 |
| 节日彩蛋 | 开 | 节日时的特别反应 |
| 媒体监控 | 开 | 是否留意你正在播放的音乐/视频 |

## 小提示

- 每次最多触发一条反应，配合冷却时间，不会连珠炮式打扰。
- 天气功能需要联网。
- 觉得某种反应多余？在面板的规则列表里单独关掉即可，也可以调高全局冷却让它更安静。
