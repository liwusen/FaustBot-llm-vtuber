# 情绪化桌面 Desktop Mood

让 Faust 感知你的真实桌面环境，并**主动做出反应**——就像一只会观察你的桌宠。它既看得见"你现在在干什么"（前台应用、全屏游戏、写代码多久、鼠标节奏、未保存文档、显卡温度），也记得住"今天过得怎么样"（清醒时段、专注/游戏时长、离开次数），还会在你不方便时闭嘴。

> **仅限 Windows。** 绝大部分感知依赖 Windows 系统能力；部分信号（环境光、蓝牙外设电量、显示器开关）取决于你的硬件与 winsdk 版本，拿不到时会**如实标注"不可用"**而不是编造。

## 感知分级：桌宠能看什么

所有感知源按隐私分三级，每级一个总开关，级别下的单个源还能再单独关闭。**关掉的源不会出现在上下文里，依赖它的规则也不会触发**（面板会显示"已关闭 / 未采集"）。

| 分级 | 默认 | 包含的信号 |
|---|---|---|
| 🟢 绿色 · 本机元数据 | 开 | 系统负载（CPU/内存/磁盘 IO/磁盘余量）、电池（电量/充电/剩余续航）、前台进程、空闲时长、节日彩蛋、窗口几何（是否全屏）、应用停留与窗口切换频率、鼠标活动（速度/抖动/停在屏幕角落）、进程增减与 CPU 占用前三、显卡（nvidia-smi）、编码活动（最近提交/改动文件数，需配置监视目录）、显示器与电源（供电/省电；显示器开关取决于 winsdk 版本）、音频设备与麦克风占用、手柄、网络（类型/SSID/信号/计量/VPN）、环境光、USB 设备增减、外设电量、外部上报（锁屏/睡眠/显示器插拔/宠物被点击）、日历时段、事件时间线、离开期间摘要、今日节律 |
| 🟡 黄色 · 文本与联网 | 开 | 窗口标题文本、媒体播放（曲名/艺人/进度）、未保存文档数、画面动态（在看还是在做）、桌面新文件、天气（会联网查询所在城市） |
| 🔴 红色 · 屏幕内容 | 关 | 剪贴板类型（代码/链接/报错/图片）。**只在内容变化时读一次判定类型，正文用后即弃、不写入上下文** |

中价感知源（进程扫描、USB、网络、外设电量、显卡、编码活动）按 30～300 秒采样，廉价源 10 秒，不会为了"实时"把 CPU 吃满。

## 它能做什么

根据环境，Faust 可能会：

- 你长时间没动 → 打个哈欠动作，或轻声搭话；回到电脑前 → 主动问候，并汇报"你不在的时候发生了什么"（编译跑完、下载完成、接了设备）；
- 你连着写了 90 分钟 → 提醒你起来动一动；窗口切得特别碎 → 问问你是不是卡住了；
- CPU / 内存 / 显卡过热 → 提醒你；电量过低 → 弹一张便签提示充电；
- 深夜还在用 → 关心你早点休息；连续几天熬夜 → 从节律档案里读出来跟你说；
- 你在用某个软件、在放音乐 → 说点应景的话；
- 检测到你在开会（麦克风被占用 / 会议软件在前台）→ **闭嘴不打扰**；
- 规则可以直接切换 Faust 的表情（感知 → 情绪闭环）。

主窗口右上角的小浮层会显示天气与你的活动状态（活动中 / 短暂离开 / 已离开 / 锁屏中）。

## 免打扰闸门与静音阀

全屏（游戏/视频）、麦克风占用、会议软件在前台、屏幕已锁、或你按下了**静音阀**时，说话/便签/表情类动作默认不发。面板上能一键静音 30 分钟 / 1 小时 / 解除；规则也可以用 `action.bypass_disturb` 强行放行，或用 `condition.when_not_disturbed` 只在安静时触发。

每一轮心跳还会结算"打扰质量"：规则触发后 30 秒内你有没有动键鼠。连续被无视的规则会自动把冷却拉长（最多 8 倍），面板「规则质量」里能看到每条规则的触发/回应/无视次数与当前冷却。

## 面板

在插件页开启后，管理面板（「感知引擎」）提供：

- **感知分级**：三级开关 + 每个感知源的单开关（含采样间隔与用途说明）；
- **场景与时间线**：一句话场景摘要、最近事件流、离开期间摘要；
- **今日节律**：清醒时段、专注/游戏累计、离开次数、活动强度；
- **数据采集**：每个源的状态（采集中 / 已关闭 / 分级已关 / 不可用原因）与当前采集到的值；
- **免打扰与静音阀**：当前是否适合打扰、原因，以及静音按钮；
- **规则质量**：每条规则的条件说明、触发/回应/无视次数、自适应冷却；
- **其他配置**：当前心情、全局冷却、天气城市、编码活动监视目录。

侧边栏还有开关可显示/隐藏右上角的天气浮层。

## 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 全局冷却 | 180 秒 | 两次主动反应之间的最短间隔，避免频繁打扰 |
| 天气城市 | 自动 | 用于获取天气的城市 |
| 编码活动监视目录 | 空 | 填一个 git 仓库路径后，才能感知"最近提交/改动文件数" |
| emotion 动作兜底情绪名 | neutral | 规则里 `emotion` 动作没写情绪名时使用 |
| 分级：绿色 / 黄色 / 红色 | 开 / 开 / 关 | 三级感知总开关 |
| 各感知源开关 | 见上表 | 单源开关，与所属分级同时为真才采集 |

## 已知限制

- 显示器开关状态：当前 winsdk 版本没有 `PowerManager.DisplayStatus`，面板会显示"未知"并给出原因；锁屏/休眠状态由 Electron 的 `powerMonitor` 事件提供，仍然准确。
- 环境光传感器、蓝牙外设电量取决于硬件与设备是否上报，缺失时面板显示不可用原因。
- 剪贴板类型属红色级，默认关闭；开启后也只保留类型与长度，不保留正文。

## 小提示

- 每次最多触发一条反应，配合冷却时间，不会连珠炮式打扰。
- 天气功能需要联网。
- 觉得某种反应多余？在面板的规则列表里单独关掉即可，也可以调高全局冷却让它更安静；想让它彻底安静一阵就按静音阀。
- 想改规则细节（条件、冷却、动作）可以直接对 Faust 说，它会走 `faustbot://plugins/desktop-mood/rules.json` 草稿 + reload 提交流程。
