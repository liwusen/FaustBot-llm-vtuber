# 搜索工具

让 Faust 能够联网搜索网页、查询维基百科。这是唯一**默认开启**的内置插件。

## 它能做什么

- **网页搜索**：Faust 遇到不确定或需要最新信息的问题时，会自动联网搜索并总结结果。
- **维基百科**：查询词条、人物、概念等百科知识。

你无需手动调用，正常对话即可。例如问「帮我查一下最近的某某新闻」「XX 是什么」，Faust 会自行决定是否搜索。

## 启用与准备

插件默认已开启。要使用网页搜索，需要一个 **SearchAPI 的 API Key**：

- 在主配置里填入 `SEARCH_API_KEY`，插件会自动使用；
- 或在插件设置里单独填写。

未配置 Key 时，网页搜索会返回失败提示，但维基百科搜索仍可用。

## 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 搜索引擎 | google | 网页搜索使用的引擎 |
| API Key | 跟随主配置 | 留默认表示使用主配置里的 Key |
| 启用网页搜索 | 开 | 关闭后 Faust 不再联网搜索 |
| 启用维基百科 | 开 | 关闭后不再查维基百科 |

## 小提示

- 两个功能可以分别开关。若你只想用维基百科、不想用付费搜索，可单独关掉网页搜索。
- 搜索需要联网。
