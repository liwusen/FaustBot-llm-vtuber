# 自动上下文管理器

> ⚠️ **该插件已弃用，不建议启用。** 它在对话中途删除历史消息，会**破坏上下文缓存**、降低缓存命中率（导致更慢、更贵）。请改用 **`/compact`** 功能来压缩长对话。

长时间聊天后，历史消息会越积越多，可能让 Faust 变慢、变「啰嗦」或抓不住重点。这个插件会**自动精简过时的用户消息**，只保留最近的若干条，同时始终保留系统设定，让对话更清爽。

## 它能做什么

- 自动丢弃较早的用户发言，只留下最近的部分。
- 系统设定（人设、规则等）永远保留，不受影响。
- 区分「你正常聊天的消息」和「系统触发器产生的消息」，分别设定保留数量。

开启后无需任何操作，它在后台自动工作。

## 启用

在插件页开启即可。

## 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 保留触发器消息数 | 3 | 系统触发器产生的消息，最多保留最近几条 |
| 保留普通消息数 | 50 | 你正常发言的消息，最多保留最近几条 |

数值越大保留越多、越省心但上下文更长；越小越精简。

## 小提示

- 它只精简**用户消息**，不影响 Faust 的回复和工具调用记录，因此不能完全控制上下文总量，而是显著减少冗余的用户发言。
- 如果你希望 Faust 记住更久远的对话，把「保留普通消息数」调大一些。
- 触发器消息通常价值较低，默认只留 3 条，可按需调整。
