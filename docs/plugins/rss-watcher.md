# RSS 感知

订阅你关注的 RSS/Atom 源，Faust 会定期抓取更新，并在你空闲时**主动播报**新闻摘要，还能在窗口顶部弹出新条目横幅。

## 它能做什么

- 管理多个 RSS 订阅（增删改、分类）。
- 定期自动抓取最新条目并保存。
- 攒够一定数量的新内容、且你正好空闲时，Faust 会主动跟你聊聊最近的新闻。
- 窗口顶部会不时闪现一条新条目横幅，可随手关闭。
- 你可以让 Faust「收藏」某条内容，它会被存入长期记忆。

## 启用与管理

在插件页开启后，会出现管理面板，你可以：

- 添加/编辑/删除订阅（填写 RSS 链接、名称、分类）；
- 浏览已抓取的条目列表；
- 立即手动抓取一次。

## 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 推送阈值 | 3 | 攒够几条新内容才主动播报 |
| 抓取间隔 | 15 分钟 | 多久自动抓取一次 |
| 静默开始 | 23:00 | 此时段内不主动打扰 |
| 静默结束 | 08:00 | 静默时段的结束时间 |
| 分类过滤 | 全部 | 只关注某个分类 |
| 最多保存条目 | 500 | 超出后清理最旧的条目 |

## 小提示

- 主动播报只在你**空闲一段时间、且不在静默时段**时发生，避免打扰。
- 想更频繁收到新闻，可调低推送阈值或抓取间隔。
- 订阅抓取失败会被记录，但不会自动禁用该订阅，请留意无效链接。
