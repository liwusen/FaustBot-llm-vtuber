# 内置插件

FaustBot 自带一批内置插件，开箱即用。它们能扩展 Faust 的能力——联网搜索、唱歌、操作电脑、感知你的桌面环境、拥有情绪等等。

## 在哪里开关插件

打开 **配置窗口 → 插件** 页面，即可看到所有插件。每个插件都有开关，点击即可启用/停用；部分插件还带有独立的设置项和管理面板。

除 **搜索工具** 外，所有内置插件**默认关闭**，需要你手动开启。修改开关或设置后，一般会即时生效。

## 插件一览

| 插件 | 作用 | 默认启用 |
|------|------|:-------:|
| [搜索工具](search-tools.md) | 让 Faust 联网搜索、查维基百科 | ✅ |
| [歌台 Song Studio](song-studio.md) | 让 Faust 用自己的音色翻唱歌曲 | ❌ |
| [UI 操作器](ui-operator.md) | 让 Faust 识屏并操作你的鼠标键盘 | ❌ |
| [自动上下文管理器](context-manager.md) | 自动精简长对话（**已弃用**，改用 `/compact`） | ❌ |
| [情绪引擎](emotion-engine.md) | 给 Faust 一套会变化的情绪与表情徽标 | ❌ |
| [剪贴板](clipboard.md) | 读写系统剪贴板（**已弃用**） | ❌ |
| [RSS 感知](rss-watcher.md) | 订阅 RSS，空闲时主动播报新闻 | ❌ |
| [情绪化桌面 Desktop Mood](desktop-mood.md) | 感知桌面环境，主动做出反应 | ❌ |

点击插件名查看它的使用指南。想自己开发插件，请看 [插件开发指南](../create-plugin-guide.md)。
