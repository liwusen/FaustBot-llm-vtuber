# UI 操作器

让 Faust 能「看」你的屏幕并直接操作鼠标和键盘，帮你完成一些图形界面上的操作。

> ⚠️ **高风险功能，默认关闭。** 开启后 Faust 可以在屏幕任意位置点击、输入文字、按快捷键。请仅在你确实需要它帮忙操作电脑、且能接受偶发误操作时开启，最好在不涉及重要数据的环境中使用。

## 它能做什么

- **识屏**：截取当前屏幕并识别上面的文字，知道界面上都有什么、在什么位置。
- **点击 / 右键**：点击屏幕上识别到的按钮或文字。
- **滚动**：向上或向下滚动页面。
- **打字 / 按键**：输入文本、按回车/ESC/F5 等单键，或按 Ctrl+C 之类的组合键。

正常对话中提出诉求即可，例如「帮我点一下那个保存按钮」，Faust 会先识屏再操作。

## 启用与准备

1. 在插件页开启本插件。
2. 首次识屏时会**自动下载文字识别（OCR）模型**，需要联网并稍等片刻。
3. 需要在有真实桌面的环境中运行（不能是纯后台/无显示器会话）。

## 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 识别语言 | 中文简体 + 英文 | OCR 识别的语言 |
| 使用 GPU 识别 | 关 | 有合适显卡时可加速识屏 |
| 识别置信度下限 | 0.3 | 过滤识别不清的文字 |
| 操作间隔 | 0.05 秒 | 每次操作之间的停顿 |
| 防呆急停 | 开 | 把鼠标猛地移到屏幕角落可紧急中止操作 |
| 打字速度 | 0.02 秒/字 | 逐字输入的间隔 |
| 滚动步长 | 300 | 每次滚动的幅度 |

## 安全建议

- 保持「防呆急停」开启：一旦 Faust 操作异常，把鼠标快速甩到屏幕角落即可立即停止。
- 截屏可能包含屏幕上的敏感信息，使用前请留意当前画面内容。
- 不建议在有重要未保存工作的界面上让它自由操作。
