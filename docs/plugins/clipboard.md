# 剪贴板

让 Faust 能够读取和写入系统剪贴板。

> ⚠️ **该插件已弃用**，默认关闭，一般无需启用。相关能力已由更完善的工具取代。

## 它能做什么

- **读取剪贴板**：把你复制的内容交给 Faust。
- **写入剪贴板**：让 Faust 把某段文字放到剪贴板，供你粘贴。

## 启用

如确有需要，可在插件页开启。

## 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 启用读取 | 开 | 允许 Faust 读取剪贴板 |
| 启用写入 | 开 | 允许 Faust 写入剪贴板 |

读、写可分别开关。

## 小提示

- Linux 用户需系统安装 `xclip` 或 `xsel` 才能正常使用。
- 由于已弃用，不建议在新场景中依赖此插件。
