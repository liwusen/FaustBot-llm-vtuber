# 歌台 Song Studio

让 Faust 用**自己的音色**翻唱你收藏的歌曲。原理是先把歌曲的人声和伴奏分离，再把人声换成 Faust 的声线，最后与伴奏合成，边唱边显示歌词。

## 它能做什么

- 你对 Faust 说「唱《XXX》」，它就会用自己的声音翻唱曲库里的这首歌。
- 说「别唱了 / 停下」即可停止。
- 唱歌时主窗口会显示一个播放器，同步滚动歌词（若提供了歌词文件）。

## 首次使用：安装运行环境

翻唱用到的 AI 模型体积较大，**不随主程序安装**。首次使用需在插件面板中点击「安装运行环境」，它会自动下载所需的 Python 环境、AI 模型和依赖（数 GB）。

- 请根据你的显卡选择合适的版本（面板中可选）。较新的显卡（如 RTX 50 系）需要选择更新的 CUDA 版本。
- 建议使用 **有CUDA的NVIDIA 显卡**以获得可用的速度。
- 若未安装环境就点歌，Faust 会提示你先去安装。
- 需要大约30分钟进行安装

## 添加歌曲

把音频文件（`.mp3` / `.wav` / `.flac` / `.m4a` / `.ogg`）放进曲库的 `source` 目录。如果同名放一个 `.lrc` 歌词文件，唱歌时就会显示歌词。之后在面板里「重新扫描」即可看到新歌。

## 使用流程

1. 在面板选择一首歌，或直接对 Faust 说「唱《歌名》」。
2. 首次翻唱某首歌需要**转换**，耗时几分钟；转换结果会被缓存，之后再唱这首歌就秒开。
3. 转换完成后自动播放，主窗口显示播放器与歌词。

## 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 参考音色 | 跟随 TTS | 决定翻唱用的音色，留空则使用 TTS 的参考音频 |
| 转换精度 | 50 | 数值越高音质越好、越慢 |
| 升降调 | 0 | 半音为单位调整音高 |
| 自动音高适配 | 开 | 自动贴合原唱音高 |
| 人声增益 | 0 dB | 微调人声与伴奏的相对音量 |
| 使用国内镜像 | 开 | 安装环境时走国内镜像加速 |

## 小提示

- 面向 Windows + NVIDIA 显卡设计。
- 一次只处理一首转换任务；转换期间可继续聊天。
- 唱歌时若 Faust 说话，歌声会自动降低音量避免盖过语音。
