# 安装指南

## 环境要求

- **Windows 10/11**（x64）
- [可选]**支持Cuda 12.1及以上的Nvidia GPU**,用于语音识别和生成
- 注:Nodejs和Python环境已内置在整合包中

## 1. 下载

请到这个链接下载整合包

[下载链接--faustbot.zip](https://github.com/liwusen/FaustBot-llm-vtuber/releases/latest)

建议解压到磁盘根目录,比如D:/

提示: FaustBot 占用空间较大,如果完全安装,大约需要20G以上

## 2. 启动

双击`frontend/start.bat`，等待1-3分钟即可

## 3. 配置

把鼠标移到Live2D模型上，点击 "配置"，在 **AI 服务商** 页面填入 API 地址,模型ID和密钥即可。详见 [配置说明](configuration.md)。
